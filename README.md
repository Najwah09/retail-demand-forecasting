\# Retail Demand Forecasting \& Inventory Optimization



An end-to-end retail analytics platform for demand forecasting and inventory optimization using the M5 Walmart historical sales dataset.



\## Project Objective



The project forecasts future product demand at store and department levels and generates data-driven inventory replenishment recommendations.



\## Tech Stack



\- Python

\- SQL

\- Google BigQuery

\- dbt

\- Prophet / ARIMA / LightGBM

\- Streamlit

\- Git \& GitHub



\## Project Architecture



M5 Dataset → Python ETL → BigQuery → dbt → Forecasting → Inventory Optimization → Streamlit Dashboard
